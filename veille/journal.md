# Journal de veille — phishing et ingénierie sociale

Sujet : évolution des techniques d’hameçonnage (IA générative, QR codes, contournement de la double authentification) et mesures de protection pour les agents d’une collectivité. Contexte : campagne de sensibilisation réalisée avec GoPhish.

Changement de sujet : 21 novembre 2026. Le sujet précédent (sauvegardes hors ligne et immuables face aux rançongiciels) est abandonné. Aucun historique antérieur n’est revendiqué.

## Sources de départ — collectées le 21 novembre 2026

### Cybermalveillance.gouv.fr — fiche réflexe hameçonnage
Source : https://www.cybermalveillance.gouv.fr/tous-nos-contenus/fiches-reflexes/hameconnage-phishing
Date de publication : non établie ; fiche évolutive, consultée le 21 novembre 2026.
Résumé : définition de l’hameçonnage, signes d’alerte, conduite à tenir en cas de clic ou de saisie d’identifiants, signalement.
Intérêt : base pour les conseils donnés aux agents après une simulation GoPhish.
Limite : fiche grand public ; ne détaille pas les protections techniques d’une messagerie d’organisation.
Analyse personnelle de Farès : à compléter.
Piste de test : comparer les signes d’alerte de la fiche avec ceux de mon modèle d’e-mail Microsoft 365 ; test non réalisé.

### ANSSI — recommandations relatives à l’authentification multifacteur et aux mots de passe
Source : https://messervices.cyber.gouv.fr/guides/recommandations-relatives-lauthentification-multifacteur-et-aux-mots-de-passe
Date : à relever sur le document.
Résumé : recommandations sur le choix des facteurs d’authentification, dont les méthodes résistantes à l’hameçonnage.
Intérêt : comprendre pourquoi un code SMS ou une notification peuvent être relayés par un faux site, contrairement à une clé FIDO2.
Limite : guide de référence général ; ne décrit pas la configuration de la mairie.
Analyse personnelle de Farès : à compléter.
Piste de test : en laboratoire, observer ce qu’une page de simulation capture avec et sans MFA ; test non réalisé.

Source : https://cert.cyber.gouv.fr/flux-rss
Intérêt : alertes et avis officiels, dont les campagnes d’hameçonnage ciblant des organisations françaises.
